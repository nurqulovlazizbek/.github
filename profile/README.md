**Morechat** — Instagram, Facebook va Telegramdagi har bir izoh va shaxsiy xabarni sotuvga aylantiradigan platforma.

- 🤖 **AI sotuvchi** — mijoz bilan **uning tilida** yozishadi, 24/7 savollariga javob beradi, telefon raqamini oladi va leadни to‘g‘ridan-to‘g‘ri CRM’ga yozadi.
- 📥 **Lead-yig‘ish** — hech bir izoh yoki DM yo‘qolmaydi; barcha kanaldan leadlar bitta joyga tushadi.
- 📊 **CRM va voronka** — Kanban bosqichlari, bitimlar, vazifalar, segmentlar, moliya-hisobotlar.
- ⚡ **Avtomatlashtirish** — vizual flow-konstruktor, triggerlar, sotuv-agentlari.
- 🛒 **E-commerce** — katalog, buyurtmalar, do‘kon (storefront).
- 🤝 **Agentliklar uchun** — bir nechta mijoz-workspace’ni bitta konsoldan boshqarish.

<br/>

**Tech:** Java · Spring WebFlux (reaktiv, R2DBC) mikroservislar · React + TypeScript · PostgreSQL · Redis · RabbitMQ.
